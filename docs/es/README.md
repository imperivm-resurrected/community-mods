# Documentación

[English](../README.md) · **Español**

El inglés es el idioma base. Aquí están las copias en español de las guías, con los mismos nombres de archivo.

## Guías

| Guía | Qué cubre |
|---|---|
| [SETUP.md](SETUP.md) | Extraer, una sola vez, los datos del juego con los que comparan las herramientas |
| [PORTING.md](PORTING.md) | Portar un mod paso a paso: autor, descarga, port, `mod.json`, validar, publicar. Mapas y aventuras (`wrap-map.js`) |
| [CIVILIZATIONS.md](CIVILIZATIONS.md) | Mods de civilización: letras e índices en uso |
| [BIG-MODS.md](BIG-MODS.md) | Mods hechos para 1.40, mods grandes hechos para HD, mapas con clases de Imperivm I |
| [TOOLS.md](TOOLS.md) | Todos los scripts de `tools/` |
| [GAMES.md](GAMES.md) | Dónde conseguir los juegos originales y sus parches; cómo ejecutarlos en Linux |
| [SOURCES.md](SOURCES.md) | Foros, servidores de Discord y sitios donde encontrar más mods |

Las reglas para colaboradores y agentes están en [`AGENTS.md`](../../AGENTS.md) (en inglés).

## Tablas

Son datos, no guías: existen solo en inglés, en [`docs/`](../README.md), y los scripts de `tools/` las leen y las escriben.

| Tabla | Qué es |
|---|---|
| [MODS.md](../MODS.md) | Lo que se puede portar. La fuente de verdad, editada a mano. La leyenda está en [How to read the tables](../MODS.md#how-to-read-the-tables) |
| [MISSING.md](../MISSING.md) | Filas sin descarga que funcione (enlaces caídos o ninguno) |
| [DEAD-LINKS.md](../DEAD-LINKS.md) | Enlaces caídos de filas que se quedan en `MODS.md` (tienen otro que funciona) |
| [PENDING.md](../PENDING.md) | Lo que falta por portar, agrupado por lo que lo frena. Generado: no se edita |
| [AUTHORS.md](../AUTHORS.md) | Modders y editores, con su cuenta de Discord y su perfil del foro cuando se encontraron, para contactarlos |
