# Documentation

**English** · [Español](es/README.md)

English is the base language. Spanish copies of the guides are in [`es/`](es/README.md), with the same file names.

## Guides

| Guide | What it covers |
|---|---|
| [SETUP.md](SETUP.md) | Extract the game data the tools compare against (once) |
| [PORTING.md](PORTING.md) | Port a mod step by step: author, download, port, `mod.json`, validate, publish. Maps and adventures (`wrap-map.js`) |
| [CIVILIZATIONS.md](CIVILIZATIONS.md) | Civilization mods: letters and indices in use |
| [BIG-MODS.md](BIG-MODS.md) | Mods made for 1.40, big mods made for HD, maps with Imperivm I classes |
| [TOOLS.md](TOOLS.md) | Every script in `tools/` |
| [GAMES.md](GAMES.md) | Where to get the original games and their patches; how to run them on Linux |
| [SOURCES.md](SOURCES.md) | Forums, Discord servers and sites where more mods can be found |

The rules for contributors and agents are in [`AGENTS.md`](../AGENTS.md).

## Tables

Data, not guides: they exist only here, in English, and the scripts in `tools/` read and write them.

| Table | What it is |
|---|---|
| [MODS.md](MODS.md) | What can be ported. The source of truth, edited by hand. The legend is under [How to read the tables](MODS.md#how-to-read-the-tables) |
| [MISSING.md](MISSING.md) | Rows with no working download (dead links or none) |
| [DEAD-LINKS.md](DEAD-LINKS.md) | Dead links of rows that stay in `MODS.md` (they have another working one) |
| [PENDING.md](PENDING.md) | What is left to port, grouped by what holds it back. Generated: don't edit |
| [AUTHORS.md](AUTHORS.md) | Modders and editors, with their Discord account and forum profile when found, to contact them |
