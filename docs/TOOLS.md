| [`audit-completeness.js`](../tools/audit-completeness.js) `<id> [--orig <zip\|folder>] [--port <folder>] [--out <folder>] [--strict] [--fresh]` \| `--self-test` | The completeness audit of a port (community-mods#53, *Completeness rule*), for any mod. Reads the original (zip/rar/folder, `extras/<id>/audit.json` or `--orig`), opens every container (`.pak`, `.bfhp`, LZIS packs, archives inside) and gives **every file and every member exactly one status**: `CLONED`, `SHIPPED-AS-IS`, `IDENTICAL-TO-HD` (same bytes, same text up to line endings, or same sprite pixels as the game), `GLOBAL` (an edit of a game file everybody shares: the list a ruleset layer carries; "carried" when its twin is in `rulesets/<id>/`), `DROPPED-ON-PURPOSE` (with a citation) or `UNCLASSIFIED`. Evidence, in order: same bytes as the game / the 1.40 base (`originals/game-140`), a documented rule, then a twin in the port (same name under the build's tags and civilization ids, same bytes, a patch of the same file, a clone class of `civs/*.json`, a `.rle` for a `.rle.mmp`) and, for tables, a check **by element** (INI by section/key and value, XML by `id`/`name`, texts by key; XML values are not compared). Writes `INVENTORY.csv` (columns `path,size,status,kind,note,sha256,level,container,group,nature,how,art_class,lives_in,now_in,evidence,ported_as,carried`; the first eleven are the Community inventory's, `nature` and `how` are filled by hand per mod) and `INVENTORY.md` to `.scratch/audit/<id>/` (totals, kind × status, **art class** 1 civilization / own names, 2 global in-game art, sound or text at a game path, 3 menu skin, and **where it must live** `root` / `rulesets/<id>/` / `skins/<id>/`, the GLOBAL list, every DROPPED row with its citation, root files that replace the game's, **collisions** with the root of every other port, patched files shared). Exit 1 if there is an UNCLASSIFIED row (a file with no twin and no explanation is UNCLASSIFIED with `evidence=lost`); `--strict` also fails on GLOBAL rows with no copy in a layer and on class-2 art in a root. `extras/<id>/audit.json`: `original`, `tags`, `language`, `leftOut` (lists of paths left out), `rules` and `explain` (each needs `reason` and `cite`). `--self-test` builds a tiny mod, game and port and checks every status, a lost file, `--strict` and the same rows twice. Needs `bsdtar`; `SDK=` and `G=` (the HD game folder, read only) for the sprite compare |

Run it **locally** after pushing the tag: `ported/` is git-ignored and built from `originals/`, so Actions cannot. Without a flag it only plans (what changed since the last release, by hashing the files); `--build` writes `.release/<tag>/`; `--upload` creates the release and uploads.
