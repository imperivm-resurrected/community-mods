| **Gathering** | |

| [`download-forum.js`](../tools/download-forum.js) | Files behind the live links of rows with no local copy → `originals/forum/<key>/files/`. Mega needs `megadl`; ModDB a browser on CDP port 9333 (Cloudflare). `--force=<keys>` downloads again |
| [`download-forum-shots.js`](../tools/download-forum-shots.js) | Screenshots in each forum topic's opening post → `originals/forum/t<id>/screenshots/` |

| [`sync-table.js`](../tools/sync-table.js) | *Type* and *Status* of every ported row from its `mod.json` |
| [`pending.js`](../tools/pending.js) | `PENDING.md` from `MODS.md` |

| [`flatten-paks.js`](../tools/flatten-paks.js) | A 1.40 mod that is a full game copy (whole `.pak` packages) → loose files, for `port-140.js` (the Greek Mod 1.8) |
| [`greek-1-8.js`](../tools/greek-1-8.js) | After `port-140.js`: the Greek Mod 1.8's Greece as an independent civilization (`greek18`, letter `Q`): renames, patches, AI as `GR18_*` |
| [`greek-1-8-scripts.js`](../tools/greek-1-8-scripts.js) | Last step of the Greek Mod 1.8: the mod's edits of the game's behavior scripts (`MILITARY_ONDIE`...) as copies `*_G18.VS` (HD's script plus the mod's edits, `git merge-file`) that the classes of its civilizations point to; the game's scripts stay as they are |
| [`shared-paths.js`](../tools/shared-paths.js) `<ported id>` | Files, class ids and entity folders a port shares with the game and with the other ports (the independence check) |

| [`port-translation.js`](../tools/port-translation.js) | A mod's translation for 1.40 (`GAME.LOC.XML`) → `loc/<language>.loc.xml` with only the texts it translated |
| [`imperivm1.js`](../tools/imperivm1.js) | Imperivm I classes → `ported/imperivm1-legacy/` |
| [`cgwar-civs.js`](../tools/cgwar-civs.js) | After `port-140.js`, before `cgwar-greece.js`: Imperial Rome (CGWAR) and Republican Rome (CGWAR), two clones of Republican Rome, each with the commands its branch of the mod had enabled (the Arena choice is not ported) |
| [`cgwar-greece.js`](../tools/cgwar-greece.js) | After `cgwar-civs.js`: the CGWAR's Greece as a new civilization |
| [`cgwar-independent.js`](../tools/cgwar-independent.js) | After `cgwar-greece.js`: the game's files it replaced become patches of what is Greek; the rest is left out. The mod's AI squad monitor runs only for the AI players of its civilizations (`GR_SquadMonitor.vs`, started by a `Main.vs` patch), the Spanish texts of the researches it renames keep their translation, and its conquest becomes one of its own next to the game's (`tools/lib/conquests.js`) |
| [`celtic-kings-adventure.js`](../tools/celtic-kings-adventure.js) | The Celtic Kings Adventure (row 202): the three ModDB zips → `ported/celtic-kings-adventure/`; its classes, commands and items as its own (`CK*`), the `.bfhp` edited in place to use them (`hpfs.js`), the texts as `loc/` |
| [`gbr-tactics.js`](../tools/gbr-tactics.js) | After `port-140.js`: GBR Tactics 2.4's eight civilizations as civilizations of their own (ids `<civ>_gbrt`, derived prefixes), its new items as patches; the mod's scripts the game's compiler refuses are fixed (see `extras/gbr-tactics/NOTES.md`) |
| [`asvrmod-vii.js`](../tools/asvrmod-vii.js) | AsvrMod VII Ancient Generals a0.8.1 (GameBanana 729311): unpacks the rar into `.scratch/` (inside the worktree, git-ignored), runs `port-140.js` and makes the game's eight civilizations as eight of its own (`agaul`, `arome`, `aimperial`, `acarthage`, `abritain`, `aiberia`, `aegypt`, `agermany`; prefixes `Aga`…`Age`), with the mod's scripts as copies (`_asv`), the behaviors the clones inherit as blocks inside the game's scripts ([`lib/asvr-inline.js`](../tools/lib/asvr-inline.js)) and its AI as `ASV_*` copies that only run for them ([`lib/asvr-ai.js`](../tools/lib/asvr-ai.js)). Also its menu skin, the one approved exception to "patches only" ([`lib/asvr-menu.js`](../tools/lib/asvr-menu.js): the rar's `MAINMENU.INI` and `MENUBACK.INI` with three edits for HD, the 20 `UI/MENU` pictures, the title and credits pictures, `TIPS.XML`, and the wall with the first frame of the strip pasted in, written by a node BMP writer, no ImageMagick; never the text tables) and the offline checks of what it writes: [`lib/asvr-refs.js`](../tools/lib/asvr-refs.js) (every picture a command, class or item names must exist; a reference that `tagCollisions` renamed to a file it never wrote goes back to the mod's own name) and [`lib/script-checks.js`](../tools/lib/script-checks.js): no `}` that closes nothing, no code after a `return`, patches applied with the engine's algorithm, class names resolved; not a compiler) |
| [`antioco-iii.js`](../tools/antioco-iii.js) | After `port-140.js`: Antíoco III el Grande (Falcata) as a content pack, no civilization: leaves out the Greek Mod 1.8 copy it came on, turns the files at the game's paths into patches, renames what the CGWAR, the MCI and the Community Mod also name (`_ant`, in the maps too), follows the 1.8's `Q*` names, adds the hero classes and icons the maps need, and puts the two adventures in `Adventures/` |
| [`greek-4-2-source.js`](../tools/greek-4-2-source.js) | The Greek Mod 4.2's source: takes the mod's folder out of Gabbo's package (GameBanana 731819, which also carries a fork of the engine) and leaves out the fork's parts, the old engine's variants and what is not ours to set (`rules/game.json`); `greek-4-2.js` reads what it makes |
| [`greek-4-2.js`](../tools/greek-4-2.js) | The Greek Mod 4.2 as its own civilizations (and Rome's and Carthage's branches); the mod's versions of the game's scripts, and the ones its classes inherit, as scripts of its own civilizations (`lib/own-scripts.js`), its AI for them (economy and tactics: `lib/greek-ai.js`; monitors, strategies and what the engine calls by name: `lib/own-ai.js`), its game modes written per civilization (`lib/mode-rules.js`), its conquests renamed and its Mediterranean with a map region, a label and a shield for Greece (`lib/conquests.js`, `lib/conquest-greece.js`); `tools/lib/` has what it shares with the others |
