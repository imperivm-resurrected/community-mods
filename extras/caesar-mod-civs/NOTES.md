# Caesar Mod 1.1.0 (Paolo Lamberto and the Greek Mod 1.9 creators)

Row 2, issue #22 (part of it: the civilizations; the maps that `require` the mod are #8). `caesar_mod.zip` (GameBanana 728740, THIONG's upload, 924 MB, `originals/gamebanana/728740/`): a Resurrected content pack of the 1.1.0 with `mod.json`, `civs/`, `patches/`, `hidden.txt`, 5,973 files. **License: CC BY-SA 4.0** (the zip's `LICENSE.txt`), so there is nothing to ask: the pack keeps `"license": "CC-BY-SA-4.0"`, `Licenses/CAESAR-CC-BY-SA-4.0.txt` (the mod's text, which asks for attribution to Paolo Lamberto and the Greek Mod creators) and `Licenses/CREDITS.txt` (the mod's own credits). `authors`: Paolo Lamberto, Greek Mod 1.9 creators, `Villoh (port)`. A pack under CC BY-SA that is derived from this one has to be CC BY-SA too: it is a question for the maintainer whether that reaches the ports that took files from this mod (the 4.2 says so in its own `mod.json`).

**The port is `caesar-mod-civs`**, not `caesar-mod`: `caesar-mod` is the id the game's GameBanana downloader gives to the original package (the lesson of `asvrmod-vii-civs`), and 25 maps name `caesar-mod` in `incompatibleWith` (below, #8).

**This port is the mod's civilizations as ten civilizations of its own, next to the game's** (AGENTS.md, *Civilizations are independent*; decided in #15: copies + room set). The game's eight are not touched, the set is not an exclusive ruleset. The reserved token is `k`: every id starts with it.

The set is named after `mod.json` `name`: **Caesar Mod 1.1.0** (16 characters, #38); the longest lobby name, `Punic Rome (Caesar)`, is 19.

**Prefix check.** `Kga Kbr Kib Keg Kge Kca Kre Kim Kpu Kgr` are in no row of `docs/CIVILIZATIONS.md` and not in `sdk/prefixes.md`, and `shared-paths.js` finds 0 class ids in common with the game and with every port in `ported/` (below). CGWAR's Greece has the **single letter `K`**: its classes are `K` + an uppercase letter (`KBarracks`, `KGuardPostSentry`), the engine matches the whole prefix followed by an uppercase letter (sdk `civilizations.md`, *Prefix convention*) and mine are `Kg` + a lowercase letter, so `KgaBarracks` is not a `K` class and `KBarracks` is not a `Kga` class; the lowercase names the engine builds are `trainpeasantk` (CGWAR) and `trainpeasantkga`... (mine), different strings. That is read from the rules and the class lists, **not tried with CGWAR and this pack active together**. The other new ports of this batch have the tokens `i`, `s`, `z`, `f`: other first letters. The ports of the parallel branches (Community Mod `f`, MCI, Secuter, the Greek 2.x PRs) are not in this worktree's `ported/`: **not compared** (Community Mod's port is pending, it is another agent's).

## Rebuild

```bash
SDK=<imperivm-resurrected>/sdk G="$HOME/.local/share/Steam/steamapps/common/Imperivm - Great Battles of Rome HD" node tools/caesar-mod.js [id ...]     # no id: everything
```

`SDK` is needed from a `.wt/` worktree (the library looks for `../imperivm-resurrected/sdk`). The tool unpacks the zip into `.scratch/caesar-src` (git-ignored, nothing is written under `originals/`), rebuilds `ported/caesar-mod-civs` (3,534 files, 1.2 GB with the movies, music and scenarios; `.gitignore` lists the folder) and copies `extras/caesar-mod-civs/mod.json` over. **The same build twice gives the same files** (two builds in a row, md5 of all 3,534 files compared: identical). Reports of the build: `raw/port-140/caesar-mod-civs.md`, `raw/caesar-mod-civs-left-out.txt`, `raw/caesar-mod-civs-own-scripts.txt`, `raw/caesar-mod-civs-global.md`, `raw/caesar-mod-civs-exit-points.txt`.

## How it is built

1. **`DATA/` goes through `tools/port-140.js`** (three-way: HD, the 1.40 files, the mod). The mod writes its class, script and command files in its own format and HD fixed files after 1.40, so a file the mod did not change is HD's, not the mod's reformatted copy: of the zip's `DATA`, 1,217 files are the mod's only, 236 are merged with HD, 436 are new, 18 have no 1.40 file to compare. **`raw/port-140/caesar-mod-civs.md` lists 242 hunks and 55 notes where the two sides touched the same lines: in each the mod's side was used and none of them was reviewed by hand.** The classes the mod wrote differently from HD but did not change against 1.40 are the mod's file as it is (elements HD has and the mod's file lacks, `projectile_class`, a `display_name`, stay as the mod ships them: that is what the mod plays with, but it is not tried here).
2. **The civilizations of the game** are cloned from HD with the mod's version of their classes and commands on top (`tools/lib/clone-civs.js`, `cloneAllOrders`); the mod's changes in the 31 base classes the clones inherit (`Hero`, `Melee`, `Unit`, `Sentry`, `RamUnit`...) are written **inside each clone**, never in HD's class.
3. **Rome.** The mod lets the player choose Republican, Imperial or Punic Rome at the town hall (`ChooseXxxRome` researches, `R*_Enable_Or_Disable_Cmd.vs` scripts that open and close the commands of each). Each branch is a civilization with the commands of its branch from the start (`tools/lib/branch.js` reads those scripts: 31, 32 and 33 commands that its scripts hide are not in `krepublic`, `kimperial`, `kpunic`); the choosing mechanism (`RTOWNHALL_CHOICE.XML`, the six scripts, `rand(3)` in the AI) is not ported. Their hero: `KrepublicHero`, `KimImperialRomanHero`, `KpuPunicRomanHero` with the hire order of the branch; **Caesar (`KreCaesar`) is the Republican branch's**, as the mod only enables "Hire Caesar" there. "Transition to Empire" is an ordinary research (it unlocks hiring Caesar), not a choice of branch: it stays. The Imperial Rome of the game (`M*`, which the mod turned into Greece) is not cloned.
4. **Greece.** The mod puts Greece in Imperial Rome's slot (race `ImperialRome`, classes `H*`, `Hhouse1-3`, `GreekHero`, walls and gates `M*`). Here its race is `kgreece` (59 classes, 20 of them city pieces) and its classes are renamed to its prefix: `HHoplite` -> `KgrHoplite`, `GreekHero` -> `KgreeceHero`, `Hhouse1` -> `Kgrhouse1`, `MWallsN` -> `KgrWallsN`, and the two commands the engine builds from the prefix, `trainpeasantkgr` and `hireheroKgr`. The text of the port that names them follows (classes, commands, scripts, AI, patches, the 8 maps of the pack that place them); a name inside a path (entity folders, pictures) stays. Its commands are `GREECE_cae.XML` (40) and patches that add its classes as sources to the game's shared commands (5). The game's AI sees it as Imperial Rome: `alias.classes` maps `MBarracks`... to the Greek ones (`alias.commands` is empty, as in the 4.2). Its random-map towns and villages are the mod's "Imperial Roman Town 1-2 / Village 1-5" (they hold the `H*` pieces): templates **`Greek Caesar Town N` / `Village N`** (7) added by a patch.
5. **Scripts** (AGENTS.md): the mod's edits of the game's behavior scripts are copies with a name of their own, `<name>_cae.vs`, and `<name>_cae_<id>.vs` where the text differs per civilization (230 files, `raw/caesar-mod-civs-own-scripts.txt`); only the clones' classes and commands point to them, the game's scripts stay the game's. The 16,286 `<method>` the clones inherit from the game's classes whose script the mod edited are written inside 767 classes. Rome's branches read `ChooseXxxRome` in some of them: the copy has the flag written in as true or false (none was left to the game's). The class ids a script writes as text are each clone's own (none of the game's own civilization classes is left in a per-civilization copy: scanned). **The tests of the civilization in the mod's scripts also accept the clones**: `.race == Britain` is `(.race == Britain || Mod_TrueRace(x) == Kbritain)`, `IsHeirOf("BVikingLord")` also `KbrVikingLord`, `Count(p, "TTeutonWolf")` the sum with the clone's (as `tools/asvrmod-vii.js` does; 38 scripts). Four scripts the game does not have and one civilization's classes use (`UNIT_CONVERT_TTEUTON*.VS`, `UNIT_CONVERT_IMILITIAMAN.VS`) name that clone's classes. `GetPlayerRace` is left alone (it returns the base).
6. **AI** (the mod rewrote all of it: 4 tactics per civilization, economy, recruitment, monitors), done as the 4.2's (`tools/lib/own-ai.js`, `greek-ai.js`): the monitors, the group strategies and `GSH_*` as `CAE_*` copies started by a patch of `Main.vs` for the AI players of the ten civilizations; what the engine calls by name (`CalcGAIKAPriority`, `EvalRecruit`, `CalcMaxTake`, `CheckMAIKA`, `GetGAIKAStrat`, `GetArmyNeed`, `HeroSkill Default`, `TSH_*`) as blocks inside the game's script that only run for the mod's civilizations; the economy loops `CAE_ES_Stronghold`, `CAE_ES_Village` (returned by a patch of `GetEconomyScript.vs`, **never started with `AIRun`**) and the helpers they start for Greece and the five flat civilizations; the five helpers the game does not have (`ESH_ArmyRecruitment`, `ESH_ArmyTechs`, `ESH_BuildCarthaginianArmy`, `ESH_SquanderGoldTechs`, `ESH_UpgradeBarracks`) declared in `AI.INI`; the tactics (4 per civilization, picked 25/25/25/25 as the mod does, with its 20 % none, stronghold only, first 2 seconds, 7000 gold) by a patch of `GetTacticScript.vs`. Engine#15 (`Sleep` inside a script started with `AIRun`): the helpers started with `AIRun` (`CAE_ESH_*`) have no `Sleep` (grep); the monitors, strategies and tactics do, as the game's own equivalents. **Rome's three branches read `ChooseXxxRome` in the economy and the army helpers, so they get the game's economy and army helpers with the mod's tactics, monitors and the by-name scripts** (the 4.2's choice for its branches); this is the weakest part of the AI port. The scripts that exist in the game and in the mod and do not test `ImperialRome` stay the game's for everybody (their edits by the mod are not in the AI: `ESH_Druids`, `ESH_FoodTrade`, `ESH_GoldTrade`, `ES_Outpost*`, `ES_Shipyard`, `AIO*`, `GS_*` without a copy...: `raw/caesar-mod-civs-left-out.txt`).
7. **Names and paths.** `tagCollisions` (tag `cae`) against the game and every port in `ported/` renamed what collides: 8 classes (`Colosseum`, `Fisherman`, `Fountain3`, `MediumRanged`, `Poseidon`...), 28 art folders, 123 files, 29 orders and 5 items with the "(cae)" tag. **The 54 scenarios, the 12 Great Battles and Great Challenges, the tutorial and the two conquests are all renamed `<name> (cae).bfhp` and their name in the menu ends with "(Caesar)"** (they collide by path with the 4.2's or the game's: the game's `Balcans`, `Crossroads`, `Island war`, `Mediterranean` and `1 - GBR Europe` are not replaced). **Renamed random-map templates (`.RM_cae.XML`) are kept as renamed.** The graphics tail is not renamed (`rle.mmp.tail`: the sprites' headers point into it). Because tagCollisions leaves some references broken, the tool fixes them in its own post-pass (and a check stops the build on any left): 12 pictures put back to the mod's name, 44 `<sounds command="VoiceX"/>` references put on the `_cae` sound entity, the editor-tree labels and lists, one winter class file (`ThermaeWinter`) given its own file name and id.
8. **Maps.** The classes of the mod that the maps place are renamed in 8 of the 69 maps (Greek ids, and the clones' ids of the mod's own classes, 37), compacting the entry where the longer ids did not fit the pages (6 entries). The maps' units are otherwise the game's classes: the balance is in the civilizations, not in a map.

## Exit points of the Greek barracks, gymnasium, temple and village

The units a building trains appear at its type-2 point; the one Greek barracks of the 2.x mods had its only point at the dead end of a corridor of its `.PASS` and units got stuck. Checked here, for the four buildings, against their `.PASS` (SDK `lib/pass.js`): the point's cell is free, a walk over free cells leaves the footprint's box, and how deep it is. **Where the cell is**: x is 1 cell per 16 units from the origin cell (63), and y needs a scale: tested on the 192 type-2 points of the game's own buildings, 138 land on a free cell with y at 1 cell per 16 units, 190 at 1.5 and 163 at 2.0, so 1.5 is used (the 2.x notes read it at 1.0; the two disagree by one or two rows, the checks below are made at both). `raw/caesar-mod-civs-exit-points.txt`:

| Building | Point | Cell (y x 1.5) | Result | Done |
|---|---|---|---|---|
| Barracks | type 2 (-32,-50) | 61,69 | free, 21 steps from leaving the box (the dead end) | **same `.PASS` (md5 0273d53b: the 1.8's) and same single point as the 2.x barracks, where the move to (-16,-50) was tried in game: moved the same way** (not tried here) |
| Gymnasium | type 2 (32,-16) | 65,66 | free, 8 of 9 free cells around, 24 steps | unchanged |
| Temple | type 2 (35,-134) | 65,77 (65,73 at 1.0) | **BLOCKED at both scales** | moved to (23,-117), cell 64,75 (free at both, 28 steps out, 6 of 9 free around): the nearest point that is free at both scales and leads out. **Not tried in game; the original is `x="35" y="-134"`** |
| Village | type 1 (90,-10), type 2 (90,5) | 69,65, 69,64 | free, 17 steps | unchanged |

What this does **not** prove: why the engine fails at a dead-end point (the 2.x notes do not prove it either), or that the temple's new point is right (it lies in the same long recess of the footprint). The temple's exit and the barracks' are the first things to try.

## Independence check

`node tools/shared-paths.js caesar-mod-civs`, with the game's data and every port that is in `ported/` of this worktree (CGWAR, the 1.8, the 4.2, the maps' packs, Secuter Fun Mod...):

```text
greek-civilization-mod: 1 files in the same path with other bytes, 708 identical, 0 class ids in common
  rle.mmp.tail
1 collisions
```

0 class ids in common with the game and with every port. The one collision is the **graphics tail**: this pack and the 4.2 (and Imperivm Legacy) each have an `rle.mmp.tail` and a pack can have one, so **they cannot be active together**. It is the engine's, not a choice: no `incompatibleWith` (AGENTS.md). Pending: *independence* with the 4.2 until the engine takes a tail per pack. The 708 identical files are what the 4.2 took from this mod. **Not run: two civilization mods active together in game**; Community Mod, MCI, Secuter and the Greek 2.x are not in this worktree.

## Validation

`validate-mod.js "$PWD/ported/caesar-mod-civs" --game "$G" --data originals/game-data/DATA` (SDK of `dev-villoh`): **3,534 files checked, 0 errors, 56 warnings** (the mod's own art: frames and rows that do not match in `HTOXOTES`, `HHERO1`, `WILDHORSE`, and terrain layers). The validator ignores what the patches do (engine #6) and does not read script code, so the build checks every script it writes (`tools/lib/script-checks.js`; **the build stops** on any failure): copies balanced like the mod's script they come from, 22 patches applied to the game's script with the engine's algorithm and balanced, 709 class strings resolved to a class of the game or of this port, the hero bases that `GetRandomHeroClass` draws have a descendant with an entity, and 3,639 picture references (and every `_cae` name) resolve. Two literals are allowed by name: `Place("TBarrackHorse" + i)` (the classes `TBarrackHorse1-5` are the mod's) and `IsHeirOf("RomanShipyard")` in the four generic mule scripts that Greece and Germany use (no Roman shipyard there). **These are not a compiler**: an undeclared variable, a wrong type or a function that does not exist pass them. The test is the game's log (`compilation error`).

Scans for what the validator does not do (they gave 0 unresolved after the fixes above): every class `entity=`/`entity_*` path (1,389 entity and sound references) resolves; every sound named in a script's `PlaySound` resolves. HD's own broken references (`WBreast`) are left alone.
